# PACKET FLOW ANALYSIS

# Steps:

1. Source device creates packet with destination IP
2. If same network → direct delivery
3. If different network → sent to default gateway
4. Switch forwards frame using MAC table
5. Router checks routing table
6. Packet forwarded to next network
7. Destination receives and replies

# Concepts:
- MAC Address Table
- ARP Resolution
- Default Gateway
- Routing Table Lookup

# Commands Used:
ping <IP>
tracert <IP>
show ip route
show arp
show mac address-table

# Result:
Successful packet delivery confirmed using ping.

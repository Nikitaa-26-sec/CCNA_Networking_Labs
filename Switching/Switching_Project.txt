 7. EtherChannel Configuration

### DC Switch ↔ Core Switch (LACP)

# DC Switch
interface range fa 0/1-4
channel-group 1 mode passive
exit

# Core Switch
interface range fa 0/1-4
channel-group 1 mode active
exit
```

### A Block ↔ Core Switch (PAgP)

```bash
# A Block
interface range fa 0/1-4
channel-group 2 mode auto
exit

# Core Switch
interface range fa 0/5-8
channel-group 2 mode desirable
exit
```

### B Block ↔ Core Switch (PAgP)

```bash
# B Block
interface range fa 0/1-4
channel-group 3 mode auto
exit

# Core Switch
interface range fa 0/9-12
channel-group 3 mode desirable
exit
```

 10. C Block Router (Router-on-a-Stick)


enable
configure terminal
hostname C_block_router

interface fa 0/0
ip address 192.168.2.2 255.255.255.0
no shutdown
exit

interface fa 0/1.1
encapsulation dot1q 70
ip address 70.0.0.1 255.0.0.0
ip helper-address 192.168.1.40
no shutdown
exit

interface fa 0/1.2
encapsulation dot1q 80
ip address 80.0.0.1 255.0.0.0
ip helper-address 192.168.1.40
no shutdown
exit

interface fa 0/1.3
encapsulation dot1q 90
ip address 90.0.0.1 255.0.0.0
ip helper-address 192.168.1.40
no shutdown
exit

interface fa 0/1
no shutdown
```
